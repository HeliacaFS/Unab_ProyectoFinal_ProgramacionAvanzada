# Sistema de Gestión de Biblioteca Digital

## Descripción
Este proyecto corresponde al **Trabajo Práctico Final - Unidad I** de la materia **Programación Avanzada (189)** en la Licenciatura en Ciencia de Datos de la Universidad Nacional Guillermo Brown.  
El sistema permite administrar **libros, usuarios y préstamos** utilizando Programación Orientada a Objetos en Python.  

Se desarrolló una versión simple, sin interfaz gráfica ni base de datos, cumpliendo con todos los requerimientos técnicos solicitados:  
- Herencia  
- Polimorfismo  
- Agregación  
- Composición  
- Decorador propio  
- Metaclase  
- Patrón de diseño (Singleton)  



## Requerimientos
- Python 3.10 o superior
